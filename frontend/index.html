How it works

Step 01

Paste your URL

Drop in any long URL. Add an optional custom alias and expiry date.

Step 02

Get link & QR

Your short link is ready instantly. Hit QR Code for a scannable code.

Step 03

Track every click

Check the Stats tab anytime to see how many times your link has been visited.

02

Command-line tool

Prefer the terminal? custom is a CLI client that shortens links and checks stats without leaving your shell.

Install

Requires Go installed.

go install github.com/ishansaini194/customurls/cmd/custom@latest
Commands
custom short <url> --alias my-link Shorten a URL with an optional custom alias
custom short <url> --qr Shorten and print a scannable QR in the terminal
custom stats <short-id> Show clicks, target URL, and expiry for a link
custom --help Full command reference
