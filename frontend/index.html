How it works

01

Paste

Drop in any long URL. Add a custom alias, expiry, or password if you want.

02

Shorten

Get a tidy customurls.in/your-name link, plus an optional QR.

03

Track

Check clicks, QR scans, and remaining time-to-live from the Stats tab.

03

Command-line tool

Prefer the terminal? custom is a CLI client that shortens links and checks stats without leaving your shell.

Install

Requires Go installed.

$go install github.com/ishansaini194/customurls/cmd/custom@latest
Commands
$custom short <url> --alias my-link
Shorten a URL with an optional custom alias
$custom short <url> --qr
Shorten and print a scannable QR in the terminal
$custom stats <short-id>
Show clicks, target URL, and expiry for a link
$custom --help
